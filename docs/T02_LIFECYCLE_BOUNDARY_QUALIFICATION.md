# T-02.2C.2B.2A — PostgreSQL lifecycle boundary qualification

Controlled non-production only; stacked on PR #17 head fd572154cf9c52a8f2994631309fdc1e6cd0d7c7 (CI #258, 157 existing Python tests and six reference tests passed; PG16.16 suite passed). No changes to R-26, database migrations or the reference controller. Adds a disposable privileged SQL probe and real database scenarios, not a production adapter.

The probe checks committed state on a fresh primary session: exact externally supplied deployment, approval ID, role/name/OID/generation and scope, evidence digest equality, approval expiry, role attributes and exact direct membership graph (including group with no inherited roles). It does not authenticate human evidence, verify the external ledger, establish primary identity in production or atomically enable routes. A true probe result is necessary but insufficient. Tests require pending denial, valid active tuple, wrong OID/scope denial, direct and transitive membership drift denial, and rejection after a successful activation transaction commits after approval expiry. No ongoing membership expiry guarantee is claimed.

The termination scenario observes an actual scoped backend, disables login, retires the exact binding, calls pg_terminate_backend with a positive wait, requires successful result, client failure and zero matching sessions, then attempts a fresh authentication and requires the login-disabled error. The bootstrap superuser is trusted and the fixture is isolated; no production credential or connection is used. NOLOGIN is not equivalent to a network fence, and zero sessions at an observed instant is not distributed fencing. Real vault and network adapters, stale-resource epoch enforcement, durable external ledger and signed human approval evidence, independent crash recovery, exact catalog manifest, role rotation/restore and split-brain qualification remain open. See PostgreSQL 16 administration functions and pg_auth_members documentation. All R-01–R-09 remain open; no acceptance or merge authorized. New tests pending CI.
