# T-02.2C.2B.1 — lifecycle controller reference

Non-production engineering reference only, outside the application package and not imported by runtime. Single trusted POSIX host, private local directory, same journal and lock path for every controller process. SQLite durable intent and compare-and-set transitions plus OS flock serialize local calls. Fresh admissions are one-shot; terminal retirement cannot reopen. Durable admitting/retiring/quarantined states require explicit retirement on recovery, never replay of admission. The reference refuses rotation to a different tuple for an existing scope. No destructive journal reset or restoration is allowed. This is not the permanent external issuance ledger or distributed fencing mechanism.

Adapter contract: block and verify the route before other retirement actions; revoke vault, disable login, retire binding, wait for and independently confirm backend termination and complete retirement evidence. Admission must independently re-read committed primary approval/binding, expiry, exact role OID/generation/catalog graph, secret readiness and external ledger; the actual enable call must reject stale epochs and expired/retired identities at the resource, not rely on a local check. The reference does not implement these external adapters. A fake implements them only to test ordering. Real routing, network, vault, independently verifiable two-human evidence, permanent ledger, watchdog/independent recovery, fencing and crash/partition behaviour remain unqualified. If the process crashes after route enablement before the journal commit, a route may remain enabled until external fencing/recovery; local intent alone does not prevent that interval. Do not deploy or claim R-01/R-03 closure. Unconfirmed fencing is an incident; quarantine in the journal is not proof of containment.

CI adds separate reference unit tests and type-check; all earlier Python scanner/tests and PostgreSQL jobs retained. No application source, migrations, or R-26 changes. No real external control plane or production credentials. Exact-head CI pending; no independent acceptance or merge authorized.
